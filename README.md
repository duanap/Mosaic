# DJQ · 角斗士棋

支持 **2、3、4 人**的方块占地策略游戏，包含同屏对战和在线房间。中文界面，适配桌面和手机，支持浅色/深色主题。

## 快速运行

安装 Node.js 22 或更高版本，在项目目录执行：

```sh
npm start
```

浏览器访问 **http://127.0.0.1:3000**。项目没有 npm 依赖，可直接启动，无需先执行 `npm install`。

```sh
npm run verify  # 语法检查 + 自动化测试 + 打包
npm run dev     # 开发时监听服务端文件变化
npm run build   # 生成 dist/，其中也可直接 npm start
```

局域网联机：按 [部署文档](docs/DEPLOYMENT.md)将 `HOST` 设为 `0.0.0.0`，其他设备访问主机的局域网 IP。公网使用请配置 HTTPS 和 `PUBLIC_ORIGIN`。

## 大厅入口

大厅提供“同屏玩法、创建房间、加入房间”三个入口，各自打开设置弹窗。同屏支持配置人机；联机创建/加入后先进入等候室，房主可添加人机并开始对局。关闭等候室弹窗仍保留房间，使用“返回房间”继续；明确退出才释放席位。

两人玩法分为20×20每人双色、14×14每人单色，每色均保留21块棋子。设置使用直接可见的单选框，按钮文字、标题和弹窗说明居中，统一字号层级；昵称与输入框同排，新打开页面会生成随机昵称，也可以自行修改。

## V1.1 功能

- 20×20 棋盘、四色各21种棋形。选择棋子后按住预览的任意实心小格拖动，短按旋转；翻转/键盘操作保留，完整棋子限制在棋盘内，松手后再确认落子。
- 2人20×20每人双色、14×14每人单色；3人轮流操作公共绿色；4人可各自计分或蓝红对黄绿组队，按队伍双色总分结算。
- 落点提示优先大块，遍历旋转/翻转，连续点击切换不重复方案，显示方案序号。
- 本地和联机均支持标准机器人，与真人混合对战；考虑面积、扩张空间、后续连接点和队友利益。
- 基础/奖励计分、无合法落点自动跳过、认输、结算、再来一局。
- 本地同屏、悔棋、本地存档恢复、JSON棋谱导出/只读复盘。
- 创建/加入房间、邀请码、服务端权威判定、实时同步、断线重连；取消准备，满员且真人在线后房主直接开始，空位可添加机器人。
- 30/60/90/120秒回合计时；真人超时使用确定性合法落子兜底，机器人独立计算；计算在工作线程中运行。
- 手机底部操作栏、键盘操作、浅/深色主题。

## 架构

本分支包含 **对局 UI 2.0**：桌面三栏、实际宽高自适应棋盘、当前棋子放大预览、手机短横屏操作抽屉和深浅色主题。规则、机器人和房间协议保持原有实现。查看[交付说明与真实截图](docs/UI_V2.md)。

原生 JavaScript ES Modules + SVG + Node.js HTTP + 经认证的 fetch/SSE。轻量回合制联机不引入 WebSocket 依赖；规则引擎独立于 UI，客户端只提交落子意图。

```text
shared/rules.mjs     规则、棋形、计分、棋谱
shared/moves.mjs     穷尽合法走法
shared/strategy.mjs  提示排序与机器人策略
server/rooms.mjs     房间、权限、回合、重连、清理
server/bots.mjs      有界机器人工作线程池
server/index.mjs     HTTP/SSE、请求边界、静态资源
public/             中文响应式界面
 tests/             规则/房间/HTTP/客户端回归与浏览器测试
 deploy/            Nginx、systemd示例
```

## 运行边界

不含账号、排位、数据库、观战服务或多进程共享房间。标准机器人是本地启发式策略，无需外部AI服务；棋力基准只与旧版首个合法走法托管比较，不代表竞技水平。新版输出v2棋谱，继续读取v1棋谱与旧本地存档。

房间保存在单进程内存中，重启服务后消失。本地对局保存在浏览器。线上席位凭据同时保存在当前标签页和浏览器本地存储中；刷新可自动重连，关闭标签页或浏览器后，在同一浏览器、同一站点的首页点击“恢复联机席位”即可恢复。新标签页不会自动抢占其他页面的席位，同一浏览器可分别保存多个席位。

恢复记录最多保留20个、每条最多8小时，且要求服务端房间及席位仍有效；等待中的离线席位会在120秒后回收，无人在线的房间会在最后一次人工活动15分钟后清理。主动退出或确认房间/席位失效会清理对应记录，短暂断网不会删除凭据。清除站点存储、使用其他浏览器/设备或浏览器禁用存储时无法保证恢复。

代码与测试不等于已完成公网部署。真实域名上的 HTTPS、反向代理和浏览器原生安全策略需参照测试/部署文档验收。
