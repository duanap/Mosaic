# 角斗士棋游戏规则

## 目标与组件

在20×20棋盘上，尽可能放出自己的棋子。使用蓝、黄、红、绿四色，每色21块，合计89小格：1格1块、2格1块、3格2块、4格5块、5格12块。

## 落子

固定按 **蓝→黄→红→绿** 循环；起始角依次是左上、右上、右下、左下。每回合选择未使用的一块棋子，可旋转、翻转，预览后确认。

1. 每色第一块必须覆盖本色起始角格。
2. 后续新棋子至少与一块已放置的同色棋子角碰角。
3. 不同棋子之间，同色不能边碰边。同一块棋子内部小格的边连接是正常的。
4. 异色可以边碰边或角碰角，但不能代替本色所需的角连接。
5. 棋子完整放在棋盘内，不能重叠。落定后不移动（本地模式的悔棋除外）。

## 2人

玩家1控制蓝+红，玩家2控制黄+绿。同一玩家的两色分别从对角出发，规则独立，一色无法行动不影响另一色。结算时先分别计分，再将两色成绩相加。

## 3人

三人分别控制蓝/黄/红，绿色是公共色。第1/2/3次绿色行动分别由玩家1/2/3操作，然后循环。主色无法落子的玩家仍参与公共色轮换。绿色仍遵守全部落子规则，成绩不计入任何玩家。

## 4人

每人一色，按四色顺序行动，分别计分。

## 跳过与结束

有合法落点时必须落子。某色全部棋子用完或无合法落点，系统自动跳过该色。对手后续落子只会减少空间，不会使已阻塞的颜色恢复可行动。全色结束后结算。

## 计分

开局前选择计分模式，同局不更改。

- 基础：每个剩余小格-1分，全部用完0分。
- 奖励：剩余小格同样扣分；某色21块全部用完得+15分；最后一块为单格棋子则再+5分，合计+20分。

玩家总分最高者胜，相同最高分并列胜利。比较的是小格数而不是剩余棋子块数。

## DJQ的线上扩展规定

以下是本项目的数字游戏约定，不作为官方桌游规则的引用。

房主选择2/3/4人、计分和30/60/90/120秒回合时限。满员、全部在线且准备后可开始。超时由服务端自动选一个合法落点。断线恢复窗口最多45秒，不延长原回合截止时间。

认输玩家不再获胜，已放棋子保留；其主色停止行动，3人局的绿色跳过该玩家。仅剩一人未认输时立即结算。等待房间中断线超过2分钟的席位会被释放；房主离开时转交房主。

提示功能提供合法落子而非最优策略。联机不支持悔棋；复盘为只读，不会覆盖在线房间的状态。
