# 角斗士棋游戏规则

## 目标与组件

在棋盘上尽可能放出自己的棋子。默认20×20使用蓝、黄、红、绿四色；两人14×14使用蓝、黄两色。每色均为21块、合计89小格：1格1块、2格1块、3格2块、4格5块、5格12块。

## 落子

固定按 **蓝→黄→红→绿** 循环；起始角依次是左上、右上、右下、左下。每回合选择未使用的一块棋子，按住棋盘预览的任意实心小格拖动位置，短按预览顺时针旋转90°，使用翻转按钮或F翻转。悬停不移动；松手只固定预览，再点击确认落子或按Enter。旋转、翻转和移动时整块棋子始终留在棋盘内；非法连接或重叠显示红色预览。

1. 每色第一块必须覆盖本色起始角格。
2. 后续新棋子至少与一块已放置的同色棋子角碰角。
3. 不同棋子之间，同色不能边碰边。同一块棋子内部小格的边连接是正常的。
4. 异色可以边碰边或角碰角，但不能代替本色所需的角连接。
5. 棋子完整放在棋盘内，不能重叠。落定后不移动（本地模式的悔棋除外）。

## 2人

20×20：玩家1控制蓝+红，玩家2控制黄+绿。同一玩家的两色分别从对角出发，规则独立，一色无法行动不影响另一色。结算时先分别计分，再将两色成绩相加。

14×14：每人控制一色，蓝色从左上角、黄色从右下角出发，双方交替行动；共42块，每色仍是完整21块。无处可放的棋子仍按原计分规则扣分。两种玩法都支持同屏、联机、机器人、悔棋、恢复和棋谱。早期14×14双色棋谱按记录保留原四色规则。

## 3人

三人分别控制蓝/黄/红，绿色是公共色。第1/2/3次绿色行动分别由玩家1/2/3操作，然后循环。主色无法落子的玩家仍参与公共色轮换。绿色仍遵守全部落子规则，成绩不计入任何玩家。

## 4人

每人一色，按四色顺序行动。可选择各自计分，或双色组队：P1蓝+P3红为A队，P2黄+P4绿为B队。组队时每人只控制自己的颜色，按队伍总分比较；队友颜色仍是异色，不能替代本色的角连接。

## 跳过与结束

有合法落点时必须落子。某色全部棋子用完或无合法落点，系统自动跳过该色。对手后续落子只会减少空间，不会使已阻塞的颜色恢复可行动。全色结束后结算。

## 计分

开局前选择计分模式，同局不更改。

- 基础：每个剩余小格-1分，全部用完0分。
- 奖励：剩余小格同样扣分；某色21块全部用完得+15分；最后一块为单格棋子则再+5分，合计+20分。

玩家总分最高者胜，相同最高分并列胜利。组队时先按颜色结算，再合计队伍两色分数，队伍同分并列。比较的是小格数而不是剩余棋子块数。

## DJQ的线上扩展规定

以下是本项目的数字游戏约定，不作为官方桌游规则的引用。

房主选择2/3/4人、四人模式、计分和30/60/90/120秒回合时限。无需准备，满员且所有真人在线后由房主开始；房主可在等待房间的空位添加标准机器人，或移除机器人让朋友加入。不能把已加入的真人替换成机器人。超时由服务端自动选一个合法落点。断线恢复窗口最多45秒，不延长原回合截止时间。

认输玩家不再获胜，已放棋子保留；其主色停止行动，3人局的绿色跳过该玩家。非组队仅剩一人未认输时立即结算。组队中一人认输队友仍可继续，认输颜色的剩余扣分计入队伍；整队认输则判负。等待房间中断线超过2分钟的真人席位会被释放；房主离开时转交其他真人，无真人时清理房间。

提示优先格数多的棋子，搜索旋转/翻转姿态；同格数先轮换不同棋形，再展示其余落点。连续点击在全部不重复候选中循环，走完后才重复，并显示方案序号。建议仍需手动确认。

标准机器人考虑面积、扩张、后续连接点和同队利益，不是最优解求解器。本地和联机都支持混合真人/机器人。联机机器人由服务端操作，浏览器不能代提交；所有真人断线时暂停机器人新任务，房间仍按时清理。断线真人不会自动被替换成机器人。

纯真人同屏悔棋退一手；本地含机器人时退回最近一次真人行动之前，连带撤销其后的机器人行动。联机不支持悔棋；复盘为只读，不会重新运行机器人。v2棋谱包含模式和席位类型，仍支持旧版v1棋谱。
