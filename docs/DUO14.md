# 两人玩法与统一排版 · 2026-10-25

同屏和创建房间选择“两人”后，有两种玩法：

| 棋盘 | 颜色分配 | 起点 | 棋子 |
| --- | --- | --- | --- |
| 20×20 | 每人双色：蓝红 / 黄绿 | 四个角 | 每色21块，共84块 |
| 14×14 | 每人单色：蓝 / 黄 | 左上 / 右下 | 每色21块，共42块 |

单色玩法使用`mode: duel`，双色使用`mode: duo`。API在14×14未指定模式时默认单色；明确的早期`duo`/14棋谱保留四色规则，旧V1/V2无尺寸记录仍按20×20读取。原三人公共色、四人个人/组队玩法保持原样。

棋盘尺寸和颜色数量贯穿规则、穷尽搜索、提示与机器人、拖动/变换边界、快照、恢复、悔棋、再开和棋谱。返回设置后同步已恢复对局的人数、棋盘和席位，避免恢复14×14后误用四人配置。

统一排版由最后加载的`public/typography.css`管理。按钮文字、页面/弹窗标题、弹窗说明和选项文案居中；主按钮图标独立放置，避免图标使文字偏心。关闭按钮使用对称留白，弹窗标题保持居中。字号分为24px标题、20px分区、16px强调、14px正文/控件、12px辅助、10px密集标签，首页主标题保留响应式展示字号。深浅色沿用现有主题变量。

昵称与输入框同排，设置选项直接可见、支持键盘操作。新页面生成随机昵称，手工修改在本次设置过程中保留。

验证：78项原生测试、45项浏览器测试通过。覆盖单色/双色库存与计分、14×14独立穷尽枚举、完整机器人对局、旧棋谱、同屏/联机/恢复/再开及鼠标/触屏。新增检查360/390/768/1440宽度的标题几何中心、按钮文字实际中心、说明居中和字号层级，并人工检查浅/深色设置、首页和单色对局截图。实体Android/iOS验收仍需实际设备。
